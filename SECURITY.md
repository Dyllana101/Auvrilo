# Security policy

## Supported versions

Only the latest version on the default branch is currently supported.

## Reporting a vulnerability

Please do not post credentials, OAuth tokens, or an unpatched vulnerability in a public issue. Use GitHub's private vulnerability reporting for this repository when enabled. If private reporting is unavailable, contact the repository maintainers privately before publishing details.

Never include real Google OAuth secrets or user data in issues, pull requests, test fixtures, or screenshots.
